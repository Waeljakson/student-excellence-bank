# بنك التميز الطلابي — مدارس المشكاة الأهلية

منصة عربية RTL لتحفيز الطلاب عبر شيكات تميز بنقاط وQR، محافظ طلابية، متجر مكافآت، تحديات ومسابقات جماعية ومنها **خميسنا غير**.

## الحقوق
برمجة وتنفيذ: **محمد صلاح الدين محمد الجمل**  
جميع الحقوق محفوظة © 2026 — مدارس المشكاة الأهلية.

## التقنية
- Vite + React 19 + TypeScript
- Neon Serverless PostgreSQL
- Neon Auth (Better Auth managed by Neon)
- QR موقّع HMAC للتحقق من الشيكات
- GitHub Pages للنشر + GitHub لإدارة الكود

## ما تم تنفيذه في النسخة الأولى
- قاعدة بيانات Neon فعلية باسم `excellence_bank`.
- Neon Auth مفعّل بالبريد وكلمة المرور.
- هيكل المدرسة/السنة/الفصل الدراسي/المراحل.
- قواعد النقاط الافتراضية، ومنها شيك التميز العملاق 40 نقطة.
- دفتر حركات Wallet Ledger غير قابل للتعديل أو الحذف؛ التصحيح يتم بحركة عكسية.
- ميزانيات شهرية لمصدري النقاط.
- متجر المكافآت والاستبدال.
- مستويات الطلاب والأوسمة والتحديات.
- نموذج كامل لمسابقة **خميسنا غير** ودوري الفصول السنوي.
- سجل تدقيق Audit Log.
- واجهة Dashboard عربية، صفحة الطلاب، المكافآت، شيكات التميز، التهيئة وخميسنا غير.
- QR وتحقق من صحة الشيك عبر `/verify`.
- تهيئة أول مدير للنظام من داخل التطبيق بعد تسجيل الدخول.

## متغيرات البيئة
انسخ `.env.example` إلى `.env.local` ثم ضع القيم الخاصة ببيئة Neon. لا ترفع `.env.local` إلى GitHub.

## التشغيل
```bash
npm install
npm run dev
```
ثم افتح `http://localhost:3000`.

## التهيئة الأولى
1. سجّل الدخول بحساب المدير.
2. افتح `/setup` واضغط **تفعيل حسابي كمدير النظام**. هذا الإجراء يعمل مرة واحدة فقط لأول مستخدم.
3. أضف/استورد الصفوف والفصول والطلاب والمعلمين.
4. ابدأ إصدار شيكات التميز.

## مبدأ أمان النقاط
رصيد الطالب لا يُخزن كرقم قابل للتعديل. الرصيد هو حاصل جمع حركات `wallet_transactions`. الجدول append-only؛ لا يسمح بتعديل أو حذف الحركة القديمة، وتتم الأخطاء بحركة عكسية مستقلة مع Audit Log.
